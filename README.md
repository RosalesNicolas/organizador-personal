# Organizador Personal

Aplicación web progresiva orientada a la organización académica, laboral y personal desde dispositivos móviles.

El proyecto centraliza cuatro áreas principales:

- **CJCC:** gestión de cursos, estudiantes, evaluaciones, recuperatorios y observaciones.
- **Piero:** registro de clases de Física, contenidos dictados y tareas asignadas.
- **UTN:** organización de materias, entregas, parciales, notas y tareas personales.
- **Gimnasio:** creación de rutinas, ejercicios, seguimiento de series y cronómetros de entrenamiento.

## Objetivo

Desarrollar una aplicación instalable en el celular que permita consultar y actualizar información desde cualquier dispositivo, con autenticación y almacenamiento en la nube.

## Tecnologías

- React
- TypeScript
- Vite
- Firebase Authentication
- Cloud Firestore
- React Router
- CSS mobile-first
- PWA

## Funcionalidades implementadas

### Autenticación

- Inicio de sesión con Google.
- Persistencia de sesión.
- Datos separados por usuario.

### Módulo UTN

- Materias iniciales: COM, DSI, ANU, Backend y Seminario.
- Gestión de entregas.
- Gestión de parciales.
- Notas y tareas personales.
- Edición de registros.
- Estados configurables.
- Archivado y restauración.
- Eliminación definitiva.
- Persistencia en Cloud Firestore.

## Diseño

La interfaz está pensada principalmente para celular, con tema oscuro y una identidad visual diferente para cada módulo:

- CJCC: rojo.
- Piero: naranja.
- UTN: azul.
- Gimnasio: verde.
